Dostępność leczenia.
Wspólny punkt odniesienia.

Atlas i Radar Kolejek NFZ porządkuje publiczne dane o dostępności świadczeń. Pozwala wyszukiwać placówki, obserwować zmiany i przygotowywać raporty na podstawie jawnych zasad.

Bez konta. Bez śledzenia.

Aplikacja działa statycznie w przeglądarce. Nie wymaga logowania i nie używa analityki śledzącej. Ustawienie motywu zapisuje lokalnie na Twoim urządzeniu. Serwery GitHub Pages i kafelków OpenStreetMap otrzymują standardowe żądania sieciowe.
